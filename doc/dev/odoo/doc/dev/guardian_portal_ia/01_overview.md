# Guardian Portal Information Architecture

## Overview
This document outlines the information architecture of the website portal from the guardian's perspective, detailing the structure, navigation, and key functionalities available to guardians.

## Main Navigation
- **Home**
  - Overview of the academy
  - Announcements and updates

- **My Kids**
  - List of children enrolled
  - Quick links to each child's profile

- **Sessions**
  - Upcoming sessions
    - Session details (date, time, location)
    - Report absence option
  - Past sessions
    - Attendance records
    - Absence reports

- **Billing**
  - Current invoices
  - Payment history
  - Billing summary

- **Profile**
  - Guardian information
  - Manage account settings
  - Change password

## Key Features
### 1. Session Management
- View upcoming sessions for each child
- Report absences with reasons and notes
- Notifications for session changes or cancellations

### 2. Billing Overview
- Access to current and past invoices
- Payment options and history
- Notifications for upcoming payments

### 3. Profile Management
- Update guardian contact information
- Manage linked children’s profiles
- Security settings (password changes, two-factor authentication)

## User Flow
1. **Login**: Guardian logs into the portal.
2. **Dashboard**: Guardian is presented with an overview of their children’s upcoming sessions.
3. **Session Interaction**: Guardian can click on a session to view details or report an absence.
4. **Billing Access**: Guardian can navigate to the billing section to view invoices and payment history.
5. **Profile Management**: Guardian can update their profile information as needed.

## Conclusion
This document serves as a guide for understanding the information architecture of the guardian portal, ensuring that guardians can easily navigate and utilize the available features to manage their children's activities effectively.
