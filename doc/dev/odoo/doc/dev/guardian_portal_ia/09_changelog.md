# Guardian Portal Information Architecture

## Overview
This document outlines the information architecture of the website portal from the guardian's perspective, detailing the structure, navigation, and key functionalities available to guardians.

## Main Navigation
- **Dashboard**
  - Overview of child's activities
  - Upcoming sessions
  - Notifications

- **My Kids**
  - List of children linked to the guardian
  - Individual profiles for each child

- **Sessions**
  - Upcoming sessions
  - Past sessions
  - Absence reporting

- **Billing**
  - Current invoices
  - Payment history
  - Billing summaries

- **Settings**
  - Profile management
  - Notification preferences
  - Guardian account settings

## Child Profile Structure
- **Profile Overview**
  - Child's name
  - Age
  - Skill group

- **Attendance**
  - Attendance history
  - Absence requests
  - Check-in status

- **Progress Reports**
  - Skill development
  - Coach feedback
  - Session summaries

## Absence Reporting
- **Report Absence**
  - Form to submit absence requests
  - Reason selection
  - Notes field

## Notifications
- **Alerts**
  - Upcoming sessions
  - Absence confirmations
  - Billing reminders

## User Experience Considerations
- **Accessibility**
  - Ensure all features are accessible to guardians with varying levels of tech proficiency.

- **Mobile Responsiveness**
  - Design should be mobile-friendly for guardians accessing the portal on different devices.

- **User Feedback**
  - Mechanism for guardians to provide feedback on portal usability and features.

## Future Enhancements
- Potential features to improve guardian experience
- Integration with external systems (e.g., calendar sync)
