# Guardian Portal Information Architecture

## Overview
This document outlines the information architecture of the website portal from the guardian's perspective, detailing the key sections, navigation paths, and user interactions.

## Main Navigation
- **Home**
  - Overview of the academy
  - Announcements and updates

- **My Kids**
  - List of children enrolled
  - Quick links to each child's profile

- **Sessions**
  - Upcoming sessions
    - Session details (date, time, location)
    - Report Absence button
  - Past sessions
    - Attendance records
    - Absence reports

- **Billing**
  - Current invoices
  - Payment history
  - Billing summary

- **Profile**
  - Guardian information
  - Child profiles
  - Settings (notification preferences, password management)

## User Flows
### Reporting an Absence
1. Navigate to **My Kids**.
2. Select the child.
3. Click on **Sessions**.
4. Click **Report Absence** for the relevant session.
5. Fill out the absence form and submit.

### Viewing Billing Information
1. Navigate to **Billing**.
2. View current invoices and payment history.
3. Click on an invoice for detailed view.

## Key Features
- **Notifications**: Alerts for upcoming sessions and billing reminders.
- **Absence Reporting**: Easy access to report absences without needing to contact staff.
- **Profile Management**: Ability to update guardian and child information.

## Conclusion
This information architecture aims to provide guardians with a clear and intuitive experience when navigating the portal, ensuring they can easily access important information and perform necessary actions.
