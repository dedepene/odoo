# Guardian Portal Information Architecture

   ## Overview
   The guardian portal provides a user-friendly interface for guardians to manage their child's participation in the academy's programs.

   ## Main Navigation
   - **My Kids**
     - View children's profiles
     - Access session schedules
   - **Sessions**
     - Upcoming sessions
     - Past sessions
   - **Absences**
     - Report an absence
     - View absence history
   - **Notifications**
     - Alerts for upcoming sessions
     - Updates from coaches

   ## User Journey
   - **Reporting an Absence**
     1. Guardian logs into the portal.
     2. Navigates to "My Kids" and selects the child.
     3. Clicks on "Report Absence" for the upcoming session.
     4. Fills out the absence form and submits.
