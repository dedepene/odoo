# Guardian Portal Information Architecture

   ## Overview
   The guardian portal provides a user-friendly interface for guardians to manage their child's tennis academy activities, including scheduling, attendance tracking, and communication with coaches.

   ## Main Navigation
   - **My Kids**: Access to children's profiles and schedules.
   - **Sessions**: View upcoming and past sessions.
   - **Absences**: Report and manage absence requests.
   - **Messages**: Communicate with coaches and staff.

   ## Key Features
   - **View Child Schedules**: Guardians can see the schedule for their children, including session times and locations.
   - **Report Absences**: A simple form to notify the academy of a child's absence.
   - **Attendance Records**: Access to attendance history for each child.
   - **Coach Communication**: Direct messaging options to reach out to coaches.

   ## User Journey
   1. Guardian logs into the portal.
   2. Navigates to "My Kids" to select a child.
   3. Views the upcoming sessions and selects one to report an absence.
   4. Completes the absence form and submits it.
   5. Receives confirmation of the absence report.
