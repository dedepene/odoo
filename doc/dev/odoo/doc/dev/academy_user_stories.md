# Guardian Portal Information Architecture

## Overview
This document outlines the information architecture of the website portal from the guardian's perspective, detailing the navigation, key features, and user interactions.

## Main Navigation
- **Dashboard**
  - Overview of child's activities
  - Upcoming sessions
  - Notifications

- **My Kids**
  - List of children linked to the guardian
  - Individual profiles for each child

- **Sessions**
  - Upcoming sessions
  - Past sessions
  - Absence reporting

- **Billing**
  - Current invoices
  - Payment history
  - Billing settings

- **Profile**
  - Guardian's personal information
  - Account settings
  - Notification preferences

## Key Features
### Dashboard
- Quick access to important updates and notifications.
- Summary of upcoming sessions for all children.

### My Kids
- Detailed view of each child's profile, including:
  - Attendance records
  - Progress reports
  - Skill group assignments

### Sessions
- Ability to view and manage sessions:
  - Report absences for upcoming sessions
  - View session details (date, time, location)
  - Access session history

### Billing
- Overview of billing items and invoices:
  - View current and past invoices
  - Payment options and history
  - Contact support for billing inquiries

### Profile
- Manage guardian account settings:
  - Update personal information
  - Change password
  - Set notification preferences (email, SMS)

## User Interactions
- **Absence Reporting**: Step-by-step process for reporting a child's absence.
- **Session Confirmation**: How guardians can confirm attendance for upcoming sessions.
- **Billing Queries**: Process for addressing billing questions or issues.

## Conclusion
This document serves as a guide to understanding the information architecture of the guardian portal, ensuring a user-friendly experience for guardians managing their children's activities.
