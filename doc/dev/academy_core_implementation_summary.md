# Academy Core Implementation Summary

## Context
Refinements to the academy coach workflow were required after the coach group to boolean sync was modernized. Navigation to the Academy Coaches list began failing in production because the custom boolean field `academy_is_coach` rejected domain operators generated by the UI.

## Key Changes
- Updated `custom_addons/academy_core/models/res_users.py`
  - Expanded `_search_academy_is_coach` to accept the `in` and `not in` domain operators in addition to `=`/`!=`.
  - Added safeguards for empty value lists and environments where the coach groups are missing, returning appropriate universal TRUE/FALSE domains.
- Added regression coverage in `custom_addons/academy_core/tests/test_coach_roles.py`
  - New scenario verifies searches combining the `academy_is_coach` field with `in` and `not in` operators to ensure coaches and non-coaches are returned as expected.

## Validation
- `python odoo-bin -c odoo.conf --test-enable --test-tags academy_core --stop-after-init -d odoo -r odoo -w letmein_n0w`

## Notes
- No tracked changes were introduced under `custom_addons/academy_schedule` while addressing the coach domain issue. The module remains untouched by this fix.
